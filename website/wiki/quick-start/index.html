Your first conversation.

You need an Android 8.0+ phone, internet access and a model API key. No Mochi account or extension is required.

1. Install Mochi

Download APK v1.0.25 ↓

ARM64 fits most phones. Open the APK and allow installation from that download app if Android asks. For updates, install over the existing app using the same signing channel; do not uninstall or clear data.

Other architectures

All builds have the same features. Choose universal if unsure; it is a larger download.

ARM64 ↓Most phones 32-bit ARM ↓Older phones x86 ↓32-bit Intel x86_64 ↓64-bit Intel / emulators Universal ↓All architectures

Release notes and checksums →

You do not need to grant every permission now. Start with text; enable microphone, notifications and other access when you use those features.

2. Connect an LLM model

Recommended: Groq, with a free API tier.

  1. Register or sign in, then create an API key.
  2. In Mochi, open Settings → AI connections → Add AI connection and choose Groq. Its endpoint is prefilled.
  3. Copy a tool-capable model ID from Groq's model guide, paste the key and save. The first connection is selected automatically; use Use to switch later.

Already have a provider? Follow the AI connection guide instead.

3. Connect speech models (optional)

Speech recognition and spoken replies are configured separately from your LLM. You can start with your phone's installed Android speech services, without an extra API key.

For cloud speech, we recommend iFlytek. Open Settings → Speech and wake → Add speech connection, follow the three-step iFlytek guide, save your credentials and tap Use. For cloud replies, enable Also use this provider for speech synthesis and choose a voice. Azure Speech is also supported.

4. Say hello

  1. Open Chat, type “Hello” and tap Send. Confirm a reply before adding other services.
  2. Hold the input to dictate; releasing fills your draft rather than sending it.
  3. For hands-free speech, switch to Companion, allow microphone access and say the selected wake phrase. Choose “Hi Mochi” or “老莫老莫” in Settings → Speech and wake.

Keep Companion visible and the screen unlocked.

Then add only what you need.

Try a calendar reminder or read a web link. The Skills page explains missing Tools. Journals and explicit memory recall start off; enable Daily journal if you want them. See capabilities and permissions before connecting documents, apps or extensions.

If something does not work

No model reply

Check the selected connection, API key, full model ID and network access. Use a model that supports tool calling; consumer chat subscriptions do not necessarily include API access.

Settings → Configuration check reports model, speech, extension and Skill setup issues. It sends a short model request that may consume quota; it does not change settings or record audio.

Text works, but speech does not

Check microphone access and the phone's installed recognition service. Wake detection works only in unlocked, foreground Companion mode. Follow the speech checklist.

A tool or reminder is unavailable

Connect and enable the required Tools; installing a Skill does not grant access. Allow notifications for reminders. Background restrictions can delay scheduled work, so do not rely on Mochi for critical alerts.

Never put API keys, passwords or verification codes in a chat or public issue.
