Mochi Wiki

Your model. Your connection.

Choose a provider below. Groq is our starting recommendation for its free API tier.

The same three fields

Open Settings → AI connections → Add AI connection. Name the connection, choose a preset, then enter your model ID and API key. Presets fill in the endpoint. The model must support tool calling.

The first saved connection is selected automatically. Later additions stay saved until you choose Use; switching cancels running local Agent tasks. Editing a saved connection with a blank key keeps that key.

Choose your provider

Groq · Recommended
  1. Register or sign in, then create an API key.
  2. Choose the Groq preset. Keep https://api.groq.com/openai/v1 and Chat Completions.
  3. Pick a Tool Use model from the model guide, paste its exact ID and your key, then save.
ModelScope
  1. Register or sign in.
  2. Get a ModelScope Access Token and paste it into the ModelScope preset.
  3. Choose a suggested model, or use Custom model with an API-enabled, tool-capable ID from the model library. Save the connection.
OpenAI
  1. Create a key in the API dashboard.
  2. Select OpenAI and keep https://api.openai.com/v1.
  3. Enter a model available to your API account with tool support, paste the key and save. New connections use Responses. See the official API guide.
Azure OpenAI
  1. Create an Azure OpenAI resource and deploy a model with tool support.
  2. Select Azure. Paste the resource endpoint and key from Keys and Endpoint.
  3. Enter the deployment name, not the model family name. New connections use Responses; if you choose Chat Completions, also fill in the supported Azure API version. Follow the Azure guide.
DeepSeek
  1. Get an API key using the official guide.
  2. Choose DeepSeek: https://api.deepseek.com, Chat Completions.
  3. Copy a currently supported tool-capable model ID, paste your key and save.
Kimi
  1. Follow the API key guide.
  2. Choose Kimi: https://api.moonshot.cn/v1, Chat Completions.
  3. Enter your key and a supported model ID from the API documentation, then save. Use API credentials, not a coding subscription credential.
GLM
  1. Get your API key and model ID from the GLM API guide.
  2. Choose GLM: https://open.bigmodel.cn/api/paas/v4, Chat Completions.
  3. Use a model with tool calling, paste the key and save.
MiniMax · China endpoint
  1. Get an API key using the China API guide.
  2. Choose MiniMax: https://api.minimax.cn/v1, Chat Completions.
  3. Enter a model available to that account and save. For a different regional endpoint, follow that provider's guide and edit the address.
Agnes-AI
  1. Use the API and model guide to obtain an API key.
  2. Choose Agnes-AI: https://apihub.agnes-ai.com/v1, Chat Completions.
  3. Copy a current tool-capable model ID, paste the key and save.
Other OpenAI-compatible APIs
  1. Choose Custom compatible API.
  2. Enter the service's API base endpoint, full model ID and API key.
  3. Choose its supported protocol under Advanced connection settings and save. A chat website URL is not an API endpoint.

Only change Advanced when needed

Responses, Chat Completions and images

New OpenAI/Azure connections default to Responses; other presets default to Chat Completions. Existing connections keep their saved choice. Mochi never silently switches protocols after an error.

Enable image input only for a model and endpoint that support it. Selecting a model does not automatically enable images. ModelScope's prefilled endpoint is editable under Advanced; other presets show it directly.

Connection fails or a key needs replacing

Check API access, full model ID, endpoint and protocol against your provider's guide. Changing provider type or endpoint host requires a new key. Older app versions with a plain model field need the full ID pasted manually.

Run Configuration check for a short model probe. Keep credentials out of screenshots, chat and issue reports.
