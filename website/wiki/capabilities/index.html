Built-in capabilities

Enable the Skills and Tools you need. Installing a Skill does not automatically grant its required access.

Voice and Companion

Local wake-word detection follows your system language: “老莫老莫” for Chinese, “Hi Mochi” for English and other languages. Choose either in Settings → Speech and wake; only one is active at a time. Follow-up listening keeps conversation flowing.

Wake listening requires visible, unlocked Companion mode. Use Android speech or save multiple iFlytek and Azure Speech accounts. Choose an account, preview its voices, and opt into cloud replies separately. See the speech guide.

Calendar, todos and reminders

Discuss a day or todo and Mochi can open its native calendar and planner at the right moment. Manage events, dated todos and reminders from the app.

Allow notifications for reminders. Android background restrictions can delay scheduled work; do not rely on Mochi for critical alerts.

Tasks and scheduled work

Track scheduled runs, Termux jobs, and authorized AgentLink remote work in Tasks. Open results and stop supported work without mixing ordinary chats or foreground Subagents into the list.

The optional signed Termux extension connects a separately installed Termux. Stopping an Agent does not stop work already submitted to Shell or a remote service.

Browser and web research

Read, navigate, click, input, and scroll on supported public HTTPS pages. Page reading keeps visible text and labeled statistics, such as likes and favorites, while identifying interactive controls separately.

Reuse valid logins inside Mochi. Take over the page for login or verification, then select Continue. Manage website data and saved accounts locally; passwords are not sent to the model. Compatibility varies: verification is not bypassed, and not every page detail can be read.

Enabled browser actions can run without per-action approval. Page content used by the Agent reaches your selected model provider.

Daily journal and memory recall
  • Recent turns and relevant older messages provide conversation context automatically.
  • Optional daily journals distill meaningful events from conversations, schedules, and Mochi task results.
  • Memory Recall uses journals to find candidate dates, then searches and reads original conversation turns for detail.

Enable Daily journal in Settings to use journals and explicit recall together; both are off by default. The Skill and Tool follow that setting. Turning it off leaves ordinary conversation context unchanged.

Journals are clues, not verbatim evidence. A missed journal search falls back to conversations; an exact date or quote can go straight to them. Search can miss information—it does not prove nothing happened.

History and search indexes stay on your phone, without a separate vector service. Relevant excerpts may reach your selected model. See the memory architecture.

Notion, Tencent Docs and Feishu

Find sources, research, create documents, and edit your work through authorized Tools. Connect Notion, Tencent Docs or Feishu from Tools.

Feishu includes guided self-built-app setup and account authorization, with search, wiki browsing, and document read/write access; no callback server to deploy. It does not support whole-document deletion, native spreadsheets, Bitable or PPT editing.

Model accounts and protocols

Save named connections, including multiple accounts with the same provider. Official endpoint presets simplify setup; Azure and custom endpoints remain available. Supply your own API key and a tool-capable model.

Choose a supported protocol under Advanced connection settings → API protocol. New OpenAI/Azure connections default to Responses; other presets and existing connections retain Chat Completions. Errors do not trigger automatic protocol switching. Follow the AI provider guide.

App control · Early access

Let Mochi open an app you selected, read supported native controls, search, click, and scroll. Ordinary popups and ads require explicit close or skip controls; this is not limited to music apps.

  1. Open Tools → App Control, enable the Tools you need, and choose Allowed apps. Music apps are selected initially; add other apps or remove any selection.
  2. Open App assistance and manually enable the Android accessibility service. Some phones also need Background pop-up permission to open Mochi over another foreground app.
  3. Start from an unlocked, foreground conversation. App Assistant is on by default and explains missing Tools; it never grants permissions. Media Control and Player access are separate and needed for media-session playback verification, not ordinary app operation.

Music is one example, not a compatibility guarantee. Exact-song playback is still being validated. A successful tap does not prove completion; returning preserves Mochi's previous page and mode.

No arbitrary screen coordinates, unattended background control, or bypassing login, payments, permission prompts, or unreadable screens. Filtered interface text used by the Agent reaches your model provider.

Community Skills

Browse, search, and install community Skills from the built-in skills.sh market. Skills guide Mochi through tasks; enabling one does not automatically enable its Tools. Check dependencies and grant only the access you need.

Connect REST APIs and MCP services

Use Tools → Add tool to connect a REST API or MCP service. For REST APIs, configure requests, authentication, and returned fields. Preview stays offline; a real API test asks first.

The REST connector supports public HTTPS JSON services on port 443, not OAuth or LAN access. Writes require confirmation and selected results go to your model. Enable both the connection and its Tools explicitly.

Optional extensions

Mi Home, Termux and WebDAV use matching, same-signed extension APKs. Open them from Mochi Tools; they have no separate launcher icon. AgentLink is an independent app.

Smart home · Mi Home

Control supported appliances and TVs, inspect device state, trigger scenes, and view the latest available camera event image in a foreground conversation.

Get Mi Home extension

  1. Install the extension from the same release/signing channel as Mochi.
  2. In Tools → Extensions → Mi Home, scan the login QR with another phone signed into Mi Home; select your devices.
  3. Return to Mochi and choose Enable tools and Skill when ready. Installation alone does not enable access.

Unofficial connector; capabilities vary by device. Event images are not live video. Control is foreground-only; acceptance is not proof of a physical result when a device cannot report its state.

Termux · Local commands

Run commands and scripts in Termux, process files it can access, and inspect output or stop jobs in Tasks. Once enabled, Tools can run from foreground chats, scheduled Agents, and Subagents.

Get Mochi Termux extension · Install official Termux

  1. Install Termux separately, plus the matching Mochi extension.
  2. Open Termux setup from Mochi Tools. Follow the external-command and Android permission guidance, then test the connection.
  3. Enable the Provider, Tools, and Skill you need. Manage submitted jobs in Tasks; disabling access blocks new calls, not existing jobs.

Full shell access under Termux permissions, not root or a sandbox. Enabled commands run without per-command confirmation. Output used by the Agent goes to your model provider.

AgentLink · Computer coding agents

Connect Android to GitHub Copilot CLI, Claude Code, Kimi Code, Qwen Code, or DeepSeek Harness on your computer. Share a chat with your terminal; optionally grant Mochi scoped access to send work and read results.

AgentLink website and setup · Android downloads, including previews

A separate product, not a Mochi extension APK. Requires a running computer Bridge and a signed-in coding agent. Mochi access is explicitly granted and foreground-only; remote work can continue after Mochi closes.

WebDAV files · Preview

Designed for Nutstore, Nextcloud, ownCloud, and compatible NAS services. Find files and read or edit Markdown in an authorized folder; optionally enable file management and transfers. No separate MCP Server required.

Get WebDAV preview extension. Real Nutstore/NAS compatibility still needs validation; start with a test folder and read-only access.

  1. Install the app and extension with matching versions and signing certificates. Open Tools → Extensions → WebDAV Files to connect.
  2. Enter the HTTPS WebDAV address, an existing authorized folder, account, and application password. Nutstore has an address preset. Never send passwords in chat.
  3. Save and check, then select Enable tools and Skill. Access starts read-only; enable writing, management, and transfer Tools separately. The Skill becomes unavailable when the extension or required read Tools are unavailable.

Not an Obsidian bidirectional sync engine or encrypted-vault decoder. Search matches filenames; text is limited to 32 KiB and binary files to 32 MiB each. Safe changes to existing files require server-provided strong ETags.

Foreground conversations only. LAN access needs separate authorization and HTTPS needs a valid certificate. File text analyzed by the Agent goes to your configured model service.

Privacy and control

Persona files, settings, conversations, memory, calendar, and todos stay on the device by default. Provider credentials use Android Keystore-backed storage.

  • Save and explicitly switch independent AI and speech accounts.
  • Enable only the Tools and Skills you trust.
  • Location is requested only when a location Tool runs.
  • The entire app is open source for review.

Local-first does not mean fully offline: model requests, optional cloud speech, and enabled external Tools send necessary content to their configured services.

Settings → Share/import lets you select multiple saved connections; importing adds accounts rather than overwriting them. Anyone holding the full share link can use its included credentials and consume quota. Share it only with people you trust.
