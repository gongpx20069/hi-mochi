Get connected

App. Bridge. Pair.

Keep your computer awake, online, and running the Bridge. Android releases are currently marked Pre-release.

  1. 1
    Install the Android app

    Download AgentLink from its own Releases page, not the Mochi extension assets. Use the same signing channel for in-place updates that preserve history.

  2. 2
    Start the computer Bridge

    Install Python 3.11+, Git, and a supported, signed-in coding agent. Follow the repository setup guide and start the Bridge. Interactive terminal chat is optional.

  3. 3
    Pair and open a chat

    In Android, open Machines → Scan QR. Compare the confirmation code and approve pairing on the computer. Create a chat with a project path on that computer.

Computer setup guide ↗Android releases ↗
Private connection, explicit pairing.

The default Dev Tunnels connection is private and authenticated, without inbound firewall ports or an extra phone VPN app. Never enable anonymous tunnel access or share pairing tokens. Credentials can expire; pair again when needed. Android background monitoring is limited to one hour, not an always-on service. Model requests still follow your coding agent provider's data policy; local project storage does not mean fully offline processing.

Explicit permission · Foreground control
  1. Install AgentLink and connect it to your computer.
  2. In Mochi Tools → AgentLink, open AgentLink and approve scoped access in its native screen.
  3. Enable the Provider, its three Tools, and the AgentLink Skill. Keep both the app and Bridge updated.

Credentials stay in AgentLink and are not included in Mochi sharing. Results used by Mochi go to its model provider. Access is not enabled for scheduled Agents or Subagents.

Closing Mochi does not stop remote tasks. Results can appear in conversation cards and Tasks, with a brief update on a later wake; background delivery depends on Android scheduling, not guaranteed instant push. Human phone/terminal input takes priority over stale automated actions.
