从下载，到第一条消息

装好两端，连接一次。

准备一部 Android 手机、一台装有 Python 3.11+ 和 Git 的电脑，以及至少一个已安装、已认证的编程 Agent。电脑需要保持唤醒、联网，并运行 Bridge。

  1. 01 / 手机

    安装 AgentLink。

    从 AgentLink Releases 下载最新 Android APK，包括预览版。更新时使用相同签名渠道覆盖安装，保留已保存的聊天。

    下载 Android APK ↗
  2. 02 / 电脑

    启动 Bridge。

    先安装你选择的 Agent，并在电脑上登录。再启动 AgentLink Server。一个 Bridge 可以发现多个 Agent，无需分别安装多个 Server。

    Windows 快速启动 ↓
  3. 03 / 连接

    扫码，选好项目。

    打开 Machines → Scan QR，核对确认码并在电脑上批准配对。然后在 Chats 选择电脑、Agent，以及这台电脑上的项目路径。

    查看配对指南 ↗
Windows PowerShell · 首次配置电脑端

在你希望存放 AgentLink 的目录运行。以下命令安装的是 Bridge，不包含各个编程 Agent。

git clone https://github.com/gongpx20069/android-agent-link.git
cd android-agent-link
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .\bridge
.\.venv\Scripts\python.exe .\bridge\run.py start

如果出现 Dev Tunnels 登录提示，按提示完成认证。保持终端运行，服务会显示配对二维码。下次启动时，在此仓库目录运行最后一条命令即可。

其他环境与完整配置 ↗
可选 · 也在终端里继续聊天

等待正在执行的任务结束，再用 Ctrl+C 停止服务。在同一个仓库目录安装终端组件，然后重新启动：

.\.venv\Scripts\python.exe -m pip install -e ".\bridge[interactive]"
.\.venv\Scripts\python.exe .\bridge\run.py start --interactive

在 Android 打开你的聊天；终端里可用 /chats 切换聊天。这是 AgentLink 的共享终端，不是对独立运行的厂商 CLI 的镜像。

更新 APK，不等于更新了电脑端。

应用与 Bridge 需要分别升级。等远端任务结束后停止 Bridge，按更新指南更新仓库和安装，再重新启动。新装 Agent 后也请重新打开终端，让 Bridge 能从 PATH 找到它。

阅读使用指南 ↗
必须安装 Mochi 或全部五个 Agent 吗？

不用。AgentLink 是独立 Android 应用与电脑端 Bridge，配置好一个编程 Agent 就可以使用。Mochi 和终端聊天都是可选的。

Agent 显示 missing 是什么意思？

Bridge 无法从自己的 PATH 找到对应 Agent 的可执行文件或所需适配器。请在电脑上安装，重新打开终端并启动 Bridge，再刷新机器页。Available 只代表找到可执行文件，不代表认证成功或模型可用。

安装缺失与列表没有选项是两回事。如果同一台电脑在 Machines 能看到某个 Agent、New session 却没有，请在问题反馈中提供应用和 Bridge 版本，以及隐去敏感信息的截图。

可以恢复任意已有会话吗？

只能恢复连接的 Agent 提供的会话，恢复能力也各不相同：DeepSeek Harness 能恢复上下文，但不能回放外部会话的旧消息。切换 Agent 不会把一个服务商的对话迁移到另一个服务商。

可以关闭应用，或者让电脑休眠吗？

电脑应保持唤醒并运行 Bridge。关闭手机界面不等于取消远端任务，但 Android 后台更新有时间限制。重新打开 AgentLink 后，可重连并确认任务的实际状态。

认识 Mochi →
明确授权 · 前台控制
  1. 安装 AgentLink，并连接电脑。
  2. 在 Mochi Tools → AgentLink 打开 AgentLink，在原生界面确认限定范围的权限。
  3. 启用 Provider、Tools 与 AgentLink Skill，并保持两款应用和 Bridge 更新。

凭据留在 AgentLink，不进入 Mochi 分享。由 Mochi 使用的结果会发送给其模型服务。执行审批仍由人决定；不向定时 Agent 或子 Agent 开放。后台结果补收受 Android 调度限制。
