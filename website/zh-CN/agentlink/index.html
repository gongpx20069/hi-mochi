把两端连接起来

安装、启动、配对。

电脑需要保持唤醒、联网并运行 Bridge。Android 安装包目前标记为 Pre-release。

  1. 1
    安装 Android 应用

    从 AgentLink 自己的 Releases 下载，而不是 Mochi 扩展附件。更新时使用相同签名渠道覆盖安装，保留聊天记录。

  2. 2
    启动电脑端 Bridge

    准备 Python 3.11+、Git，以及已登录的受支持编程 Agent。按仓库指南安装并启动 Bridge；交互式终端聊天是可选项。

  3. 3
    扫码配对，开始聊天

    在 Android 打开 Machines → Scan QR，核对确认码并在电脑上批准配对。创建聊天时，选择电脑上的项目路径。

私有连接，明确配对。

默认使用经过身份验证的私有 Dev Tunnels，无需开放入站防火墙端口，也不需要给手机另装 VPN。不要开启匿名访问或分享配对令牌；凭据过期时需要重新配对。Android 后台监控最长一小时，并非永久在线服务。模型请求仍遵循编程 Agent 服务商的数据政策，项目保存在本机不等于完全离线处理。

已经在用 Mochi？
让它也能连接你的工作。

AgentLink 可以独立使用。明确授权后，Mochi 能发现已授权的工作区、创建或继续共享聊天、发送任务，并读取进展和结果。

探索 Mochi 的扩展能力 →
明确授权 · 前台控制
  1. 安装 AgentLink，并连接电脑上的 Bridge。
  2. 在 Mochi Tools → AgentLink 打开配套应用，在原生界面确认限定范围的权限。
  3. 启用 Provider、三个 Tools 和 AgentLink Skill；同步更新应用与 Bridge。

凭据保留在 AgentLink，不进入 Mochi 分享。由 Mochi 分析的结果会发送给其模型服务；不向定时 Agent 或子 Agent 开放。

关闭 Mochi 不会停止远端任务。结果可进入对话卡片与任务中心，也可在之后唤醒时简短播报；后台补收受 Android 调度限制，不保证即时推送。人工在手机或终端的输入优先于过期自动操作。
