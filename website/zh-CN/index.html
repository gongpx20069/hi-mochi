隐私从本地开始

你的伙伴，
你的 Provider，你的选择。

Persona 文件、设置、对话、记忆、日历和待办默认保存在设备本地，Provider 凭据使用 Android Keystore 支持的安全存储。

  • ✓ 独立保存 AI 与语音账号，由你明确选择当前连接
  • ✓ 只启用你信任的 Tools 与 Skills
  • ✓ 仅在定位 Tool 执行时请求当前位置
  • ✓ 整个应用开源，可直接审查实现

本地优先不等于完全离线：模型请求、可选云端语音和已启用的外部 Tools 会将必要内容发送给对应服务。设置顶部的“分享/导入”支持勾选多个连接，导入时新增账号而非覆盖。持有完整分享链接的人可以使用其中的凭据并消耗额度，请只分享给可信的人。

把 Mochi 带回家

三步，让旧手机重新有用。

无需注册 Mochi 账号，也没有 Mochi 订阅费。AI 服务由你选择，服务商调用与可选云端语音可能产生费用。

  1. 1
    安装或更新

    下载 v1.0.13。大多数手机选择 arm64-v8a，较老的 ARM 设备选择 armeabi-v7a；不确定时选择 universal。更新时使用相同签名渠道直接覆盖安装，不要卸载，以保留数据。

  2. 2
    添加连接

    打开“设置 → AI 连接 → 添加 AI 连接”，选择预设并填写模型与 API 密钥。后续新增连接不会自动切换，点击“使用”再生效；切换 AI 会取消正在运行的本机 Agent 任务。

  3. 3
    开始交流

    直接打字，或授权麦克风后语音交流；需要时开启“Hi Mochi”。Android 系统语音已内置，也可添加语音连接并点击“使用”；切换语音只停止当前语音交互与试听，不影响文字对话和后台工作。
