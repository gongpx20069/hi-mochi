从简单开始

三步，开始第一次对话。

  1. 1
    安装老莫

    下载 v1.0.22；升级时覆盖安装，保留数据。

  2. 2
    连接模型

    推荐魔搭 ModelScope，用免费 API 额度入门。粘贴 Token，选择模型。

  3. 3
    打个招呼

    先从对话模式开始。内置系统语音，无需安装扩展。
