三步连接 Termux
  1. 另行安装 Termux，以及与 Mochi 配套的扩展 APK。
  2. 从 Mochi Tools 打开配置，按引导允许外部命令、授予 Android 权限并测试连接。
  3. 启用需要的 Provider、Tools 和 Skill。已提交工作在任务中心管理；关闭开关只阻止新调用，不停止已有任务。

这是 Termux 权限下的完整 Shell，不是 Root，也不是安全沙箱。启用后不逐条确认命令；供 Agent 分析的输出会发送给你配置的模型服务。

WebDAV 文件扩展 · 预览

让云端笔记，
成为对话中的资料。

面向坚果云、Nextcloud、ownCloud 和兼容 NAS，在授权目录中查找文件、阅读或编辑 Markdown 笔记，也可按需开启文件管理与传输。无需另行部署 MCP Server。

“找文件名包含项目计划的笔记，读完后帮我总结。”

已合并至 main，尚未包含在公开 Release 中；v1.0.14 不含该扩展。真实坚果云/NAS 兼容性仍待验证，当前需从源码构建配套主应用和扩展。

查看预览使用指南 →
预览配置与权限
  1. 安装同版本、同签名的主应用与扩展，从“工具 → 扩展 → WebDAV 文件”打开连接。
  2. 填写 HTTPS WebDAV 地址、已存在的授权目录、账号和应用密码；坚果云有预设地址。不要把密码发到聊天中。
  3. 保存并检查后选择“启用工具和 Skill”。默认只读；写入、管理和传输工具需单独开启。扩展或必需读取工具不可用时，Skill 暂停提供能力。

这不是 Obsidian 双向同步引擎，也不会解密加密仓库。搜索匹配文件名，文本上限 32 KiB，二进制单文件上限 32 MiB；安全修改已有文件需要服务器提供强 ETag。

仅用于前台对话。局域网 NAS 需单独授权，HTTPS 必须有有效证书。交给 Agent 分析的文件文本会发送给你配置的模型服务。

米家、Termux 和 WebDAV 扩展不增加独立桌面图标，从 Mochi Tools 进入配置；AgentLink 则有自己的应用。它们都不是基础聊天的前提，请按需连接、明确启用。

隐私从本地开始

你的伙伴，
你的 Provider，你的选择。

Persona 文件、设置、对话、记忆、日历和待办默认保存在设备本地，Provider 凭据使用 Android Keystore 支持的安全存储。

  • ✓ 独立保存 AI 与语音账号，由你明确选择当前连接
  • ✓ 只启用你信任的 Tools 与 Skills
  • ✓ 仅在定位 Tool 执行时请求当前位置
  • ✓ 整个应用开源，可直接审查实现

本地优先不等于完全离线：模型请求、可选云端语音和已启用的外部 Tools 会将必要内容发送给对应服务。设置顶部的“分享/导入”支持勾选多个连接，导入时新增账号而非覆盖。持有完整分享链接的人可以使用其中的凭据并消耗额度，请只分享给可信的人。

把 Mochi 带回家

三步，让旧手机重新有用。

无需注册 Mochi 账号，也没有 Mochi 订阅费。AI 服务由你选择，服务商调用与可选云端语音可能产生费用。

  1. 1
    安装或更新

    下载 v1.0.14。大多数手机选择 arm64-v8a，较老的 ARM 设备选择 armeabi-v7a；不确定时选择 universal。更新时使用相同签名渠道直接覆盖安装，不要卸载，以保留数据。

  2. 2
    添加连接

    打开“设置 → AI 连接 → 添加 AI 连接”，选择预设并填写模型与 API 密钥。后续新增连接不会自动切换，点击“使用”再生效；切换 AI 会取消正在运行的本机 Agent 任务。

  3. 3
    开始交流

    直接打字，或授权麦克风后语音交流。在“设置 → 语音与唤醒”开启唤醒，默认跟随系统选择“老莫老莫”或“Hi Mochi”，也可手动指定。Android 系统语音已内置，可选添加云端语音连接。

配置遇到问题？

打开“设置 → 配置自检”，查看 AI、语音、扩展和 Skill 依赖的检查结果及修复入口。自检会发送一次短文本模型请求，可能消耗额度；不会自动修改设置或录音。真实语音效果仍需麦克风测试与音色试听。切换语音连接只停止当前语音交互与试听，不影响文字对话和后台工作。
