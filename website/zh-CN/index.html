下载米家扩展 ↓
三步连接米家
  1. 安装与 Mochi 同一发布及签名渠道的扩展 APK。
  2. 进入 Tools → Extensions → 米家，用另一台已登录米家的手机扫码确认，选择需要连接的设备。
  3. 返回 Mochi，准备好后选择“启用工具和 Skill”；仅安装不会自动启用权限。

非小米官方连接器，能力取决于设备；事件图片不是实时视频。仅用于前台控制，设备无法读回状态时，“指令已接受”不代表物理效果已确认。

让手中的手机，

在 Termux 中运行命令和脚本、处理它有权访问的文件，并在任务中心查看输出或停止工作。连接并启用后，前台对话、定时 Agent 和子 Agent 都能调用。

下载 Termux 扩展 ↓ 安装官方 Termux ↗
三步连接 Termux
  1. 另行安装 Termux，以及与 Mochi 配套的扩展 APK。
  2. 从 Mochi Tools 打开配置，按引导允许外部命令、授予 Android 权限并测试连接。
  3. 启用需要的 Provider、Tools 和 Skill。已提交工作在任务中心管理；关闭开关只阻止新调用，不停止已有任务。

这是 Termux 权限下的完整 Shell，不是 Root，也不是安全沙箱。启用后不逐条确认命令；供 Agent 分析的输出会发送给你配置的模型服务。

独立应用 + 电脑端 Bridge

离开电脑，
也不中断工作。

AgentLink 让 Android 手机连接电脑上的编程 Agent。手机与终端继续同一个对话；也可以明确授权 Mochi，替你发送工作、读取进展和结果。

认识 AgentLink → 下载 Android 预览版 ↗

这是独立产品，不是 Mochi 扩展 APK。需要电脑运行 Bridge 并登录编程 Agent。Mochi 仅在明确授权后进行前台操作；关闭 Mochi 不会停止远端工作。

米家与 Termux 扩展不增加独立桌面图标，从 Mochi Tools 进入配置；AgentLink 则有自己的应用。它们都不是基础聊天的前提，请按需连接、明确启用。

隐私从本地开始

你的伙伴，
你的 Provider，你的选择。

Persona 文件、设置、对话、记忆、日历和待办默认保存在设备本地，Provider 凭据使用 Android Keystore 支持的安全存储。

  • ✓ 独立保存 AI 与语音账号，由你明确选择当前连接
  • ✓ 只启用你信任的 Tools 与 Skills
  • ✓ 仅在定位 Tool 执行时请求当前位置
  • ✓ 整个应用开源，可直接审查实现

本地优先不等于完全离线：模型请求、可选云端语音和已启用的外部 Tools 会将必要内容发送给对应服务。设置顶部的“分享/导入”支持勾选多个连接，导入时新增账号而非覆盖。持有完整分享链接的人可以使用其中的凭据并消耗额度，请只分享给可信的人。

把 Mochi 带回家

三步，让旧手机重新有用。

无需注册 Mochi 账号，也没有 Mochi 订阅费。AI 服务由你选择，服务商调用与可选云端语音可能产生费用。

  1. 1
    安装或更新

    下载 v1.0.13。大多数手机选择 arm64-v8a，较老的 ARM 设备选择 armeabi-v7a；不确定时选择 universal。更新时使用相同签名渠道直接覆盖安装，不要卸载，以保留数据。

  2. 2
    添加连接

    打开“设置 → AI 连接 → 添加 AI 连接”，选择预设并填写模型与 API 密钥。后续新增连接不会自动切换，点击“使用”再生效；切换 AI 会取消正在运行的本机 Agent 任务。

  3. 3
    开始交流

    直接打字，或授权麦克风后语音交流；需要时开启“Hi Mochi”。Android 系统语音已内置，也可添加语音连接并点击“使用”；切换语音只停止当前语音交互与试听，不影响文字对话和后台工作。
