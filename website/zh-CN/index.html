隐私从本地开始

你的伙伴，
你的 Provider，你的选择。

Persona 文件、设置、对话、记忆、日历和待办默认保存在设备本地，Provider 凭据使用 Android Keystore 支持的安全存储。

  • ✓ 自选 OpenAI、Azure OpenAI 或兼容服务端点
  • ✓ 只启用你信任的 Tools 与 Skills
  • ✓ 仅在定位 Tool 执行时请求当前位置
  • ✓ 整个应用开源，可直接审查实现

和其他云端 AI 应用一样，回答请求所需的内容会发送给你配置的 Provider。Mochi 会明确展示这条边界，而不是把它隐藏起来。

把 Mochi 带回家

三步，让旧手机重新有用。

无需注册 Mochi 账号，也没有订阅费。由你选择为它提供智能的 AI 服务。

  1. 1
    安装

    下载 v1.0.6。大多数手机选择 arm64-v8a，较老的 32 位 ARM 设备选择 armeabi-v7a；不确定时选择 universal。

  2. 2
    连接

    在设置中填写 AI Provider 端点、模型名称与 API 密钥。

  3. 3
    开始交流

    启用你信任的 Tools，然后打字、点击麦克风或说“Hi Mochi”。
