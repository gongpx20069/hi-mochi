选好模型，就能开始。

推荐魔搭 ModelScope，用免费 API 额度入门。已有其他服务？展开对应一项即可。

首选：魔搭 ModelScope

打开设置 → AI 连接 → 添加 AI 连接，选择魔搭 ModelScope，然后完成三步：

  1. 注册或登录魔搭，在右上角头像菜单中绑定阿里云账号（官方绑定教程）。
  2. 获取该魔搭账号的 Access Token，粘贴到老莫。
  3. 选择下拉推荐模型；不满意可选自定义，从模型库复制支持 API 和工具调用的完整 ID，然后保存。

入口与基本配置

打开设置 → AI 连接 → 添加 AI 连接，填写连接名称并选择服务商预设。地址会自动填写，再填模型 ID和密钥即可。模型需要支持工具调用。

第一个连接自动选中；后续新增连接，点击使用再切换。切换会取消正在运行的本地 Agent 任务；编辑已有连接时，密钥留空表示保留原密钥。

其他服务商

Groq
  1. 注册或登录，然后创建 API Key。
  2. 选择 Groq 预设，保持 https://api.groq.com/openai/v1 与 Chat Completions。
  3. 从模型指南选择支持 Tool Use 的模型，填写完整 ID 和密钥后保存。
OpenAI
  1. 在 API 控制台创建密钥。
  2. 选择 OpenAI，保持 https://api.openai.com/v1。
  3. 填写 API 账号可用且支持工具调用的模型与密钥后保存。新连接默认使用 Responses，具体模型见官方 API 指南。
Azure OpenAI
  1. 创建 Azure OpenAI 资源，部署支持工具调用的模型。
  2. 选择 Azure，从资源的密钥和终结点复制地址与密钥。
  3. 模型字段填写部署名称，不是模型系列名。新连接默认 Responses；选择 Chat Completions 时，还要填写支持的 Azure API 版本。参阅 Azure 指南。
DeepSeek
  1. 按官方指南获取 API Key。
  2. 选择 DeepSeek：https://api.deepseek.com，Chat Completions。
  3. 复制当前支持工具调用的模型 ID，填入密钥并保存。
Kimi
  1. 按 API Key 指南获取密钥。
  2. 选择 Kimi：https://api.moonshot.cn/v1，Chat Completions。
  3. 填写 API 文档中支持的模型 ID 和密钥并保存。使用 API 凭据，而不是编程套餐凭据。
GLM
  1. 从 GLM API 指南获取密钥与模型 ID。
  2. 选择 GLM：https://open.bigmodel.cn/api/paas/v4，Chat Completions。
  3. 确认模型支持工具调用，粘贴密钥并保存。
MiniMax · 国内接口
  1. 按国内 API 指南获取密钥。
  2. 选择 MiniMax：https://api.minimax.cn/v1，Chat Completions。
  3. 填写对应账号可用的模型并保存；其他区域服务需按其指南修改地址。
Agnes-AI
  1. 通过 API 与模型指南获取密钥。
  2. 选择 Agnes-AI：https://apihub.agnes-ai.com/v1，Chat Completions。
  3. 复制当前支持工具调用的模型 ID，填入密钥并保存。
其他 OpenAI 兼容 API
  1. 选择自定义兼容 API。
  2. 填写服务商提供的 API 基础地址、完整模型 ID 和 API Key。
  3. 在高级连接设置中选择服务支持的协议并保存。聊天网页地址不等于 API 地址。

需要时，再改高级设置

Responses、Chat Completions 和图片输入

新建 OpenAI／Azure 连接默认 Responses，其他预设默认 Chat Completions。已有连接保留原协议，报错后不会自动切换。

仅在模型和接口支持图片时开启图片输入；选择模型不会自动开启图片。魔搭地址在高级设置中修改，其他预设直接显示地址字段。

连接失败，或需要更换密钥

按服务商指南核对 API 权限、完整模型 ID、地址和协议。更换服务类型或地址主机时，需要新密钥。旧版应用若只显示模型输入框，直接粘贴完整 ID。

可运行配置自检发送简短请求排查。不要在截图、聊天和公开反馈中暴露凭据。
