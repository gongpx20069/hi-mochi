技能、工具与扩展

找到需要的能力，展开查看配置和权限。基础使用不需要安装扩展。

内置能力可选扩展隐私与控制

内置能力

按需开启技能和工具。安装技能不会自动授予它需要的权限。

语音与陪伴

本地唤醒默认跟随系统：中文使用“老莫老莫”，英文及其他语言使用“Hi Mochi”。在“设置 → 语音与唤醒”中可手动选择，一次只启用一个词；回答后自动继续聆听。

唤醒聆听仅在已解锁、前台可见的陪伴模式下工作。使用 Android 系统语音，或保存多个讯飞、Azure Speech 账号；自主切换连接、试听音色，并单独选择是否使用云端语音播报。详见语音连接指南。

日历、待办与提醒

谈到某天或待办时，Mochi 能在恰当时机打开自己的原生日历与计划页面，在应用中管理日程、带日期的待办和提醒。

提醒需要通知权限。Android 后台限制可能延迟定时任务，不要完全依赖老莫发送关键提醒。

任务中心与定时工作

在任务中心查看定时执行、Termux 工作和已授权的 AgentLink 远端任务，打开结果或停止支持取消的工作。普通聊天及其前台 Subagent 留在对话中，不挤进任务列表。

可选的 Mochi 签名 Termux 扩展需要另行安装 Termux。停止 Agent 不会自动停止已经提交的 Shell 或远端工作。

浏览器与网页研究

在支持的公开 HTTPS 网页上阅读、导航、点击、输入和滚动。页面读取保留可见正文以及点赞、收藏等统计的标签与数值；可操作控件单独识别。

复用 Mochi 内的有效网站登录。需要登录或验证时，由你接管网页，完成后点击“继续”；网站与登录管理可保存账号、管理网站数据。密码留在本机，不发送给模型。网站兼容性有差异，不绕过验证码，也不保证所有页面信息都可读取。

已开启的浏览器操作可不经逐次审批执行。供 Agent 使用的页面内容会发送给你选择的模型服务。

每日小记与回忆检索
  • 近期对话与相关旧消息自动进入上下文，让交流保持连贯。
  • 可选的每日小记，从对话、日程和 Mochi 任务结果中提炼有意义的事件。
  • 回忆检索先从简短小记定位候选日期，再按需搜索、读取原始对话。

在设置中开启每日小记，即可同时使用小记和主动回忆检索；两者默认关闭，Skill 与 Tool 随该设置同步。关闭后，普通对话上下文不受影响。

小记是线索，不是原话。小记未命中时回查对话；已知明确日期或原句，也可以直接搜索对话。检索可能遗漏信息，未找到不代表没有发生。

历史与检索索引保存在手机本地，无需额外向量服务；相关片段可能发送给你选择的模型。详见记忆架构说明。

Notion、腾讯文档与飞书

通过已授权的工具查找资料、调研主题、创建和编辑文档。在工具页连接 Notion、腾讯文档或飞书。

飞书提供企业自建应用配置与账号授权引导，支持搜索、知识库浏览和文档读写，无需自行部署回调服务器；不支持整篇文档删除、原生电子表格、多维表格或 PPT 编辑。

模型账号与协议

保存多个命名连接，同一服务商也能使用不同账号。官方地址预设降低配置难度，同时保留 Azure 和自定义端点；填写自己的 API 密钥与支持工具调用的模型即可。

在“高级连接设置 → API 协议”中按服务商和模型支持选择。新建 OpenAI/Azure 连接默认 Responses，其他预设和旧连接保留 Chat Completions；报错后不会自动切换协议。详见模型连接指南。

应用操作 · 初期体验

打开你允许操作的应用，读取支持的原生控件，搜索、点击与滚动。遇到普通弹窗或广告，通过明确的关闭、跳过按钮继续任务；不只适用于音乐应用。

  1. 进入“工具 → 应用操作”，开启需要的工具，在“允许操作的应用”中选择目标。初始选择音乐类应用，也可以添加其他应用或清空选择。
  2. 打开“应用操作辅助”，手动授予 Android 无障碍权限。部分手机还需允许“后台弹出界面”，才能在其他应用位于前台时打开 Mochi。
  3. 从手机已解锁的前台对话发起任务。应用助手默认开启，缺少工具时会指引配置，不会自动授权。媒体控制与播放器访问独立，用于核验媒体会话中的播放状态，不是普通应用操作的前提。

音乐只是使用示例，不代表兼容性保证；完整点歌播放流程仍在验证。点击成功不等于任务完成，返回时保留 Mochi 原来的页面与模式。

不提供任意坐标点击或无人值守的后台操控，不绕过登录、支付、权限确认或不可读取的界面。供 Agent 使用的过滤后界面文本会发送给你配置的模型服务。

社区技能

从内置 skills.sh 市场浏览、搜索和安装社区技能，让 Mochi 按流程处理你关心的任务。启用技能不会自动打开它依赖的工具；先检查依赖，再决定授权。

连接 REST API 与 MCP 服务

从“工具 → 添加工具”连接 REST API 或 MCP 服务。REST API 可配置请求、鉴权与需要的返回字段；预览不联网，真实测试前会询问。

REST 连接器面向公网 HTTPS 443 的 JSON 服务，不包含 OAuth 或局域网接入。写入需确认，结果会提供给你配置的模型；连接和工具都需明确启用。

可选扩展

米家、Termux 和 WebDAV 使用同版本、同签名的扩展 APK，从 Mochi 工具页进入配置，不增加独立桌面图标。AgentLink 是独立应用。

智能家居 · 米家

控制支持的家电和电视、查看设备状态、触发手动场景，也能在前台对话中查看和分析摄像头最新可用的事件图片。

获取米家扩展

  1. 安装与 Mochi 同一发布及签名渠道的扩展 APK。
  2. 进入工具 → 扩展 → 米家，用另一台已登录米家的手机扫码确认，选择需要连接的设备。
  3. 返回 Mochi，准备好后选择“启用工具和 Skill”；仅安装不会自动启用权限。

非小米官方连接器，能力取决于设备；事件图片不是实时视频。仅用于前台控制，设备无法读回状态时，“指令已接受”不代表物理效果已确认。

Termux · 本机命令

在 Termux 中运行命令和脚本、处理它有权访问的文件，并在任务中心查看输出或停止工作。连接并启用后，前台对话、定时 Agent 和子 Agent 都能调用。

获取 Mochi Termux 扩展 · 安装官方 Termux

  1. 另行安装 Termux，以及与 Mochi 配套的扩展 APK。
  2. 从 Mochi 工具页打开配置，按引导允许外部命令、授予 Android 权限并测试连接。
  3. 启用需要的 Provider、Tools 和 Skill。已提交工作在任务中心管理；关闭开关只阻止新调用，不停止已有任务。

这是 Termux 权限下的完整 Shell，不是 Root，也不是安全沙箱。启用后不逐条确认命令；供 Agent 分析的输出会发送给你配置的模型服务。

AgentLink · 电脑编程 Agent

用 Android 连接电脑上的 GitHub Copilot CLI、Claude Code、Kimi Code、Qwen Code 或 DeepSeek Harness，与终端共享聊天。也可按需授权 Mochi，替你发送工作、读取进展与结果。

AgentLink 官网与配置 · Android 下载，含预览版

这是独立产品，不是 Mochi 扩展 APK。需要电脑运行 Bridge 并登录编程 Agent。Mochi 仅在明确授权后进行前台操作；关闭 Mochi 不会停止远端工作。

WebDAV 文件 · 预览

面向坚果云、Nextcloud、ownCloud 和兼容 NAS，在授权目录中查找文件、阅读或编辑 Markdown 笔记，也可按需开启文件管理与传输。无需另行部署 MCP Server。

获取 WebDAV 预览扩展。真实坚果云/NAS 兼容性仍待验证，建议先授权测试目录并保持只读。

  1. 安装同版本、同签名的主应用与扩展，从“工具 → 扩展 → WebDAV 文件”打开连接。
  2. 填写 HTTPS WebDAV 地址、已存在的授权目录、账号和应用密码；坚果云有预设地址。不要把密码发到聊天中。
  3. 保存并检查后选择“启用工具和 Skill”。默认只读；写入、管理和传输工具需单独开启。扩展或必需读取工具不可用时，Skill 暂停提供能力。

这不是 Obsidian 双向同步引擎，也不会解密加密仓库。搜索匹配文件名，文本上限 32 KiB，二进制单文件上限 32 MiB；安全修改已有文件需要服务器提供强 ETag。

仅用于前台对话。局域网 NAS 需单独授权，HTTPS 必须有有效证书。交给 Agent 分析的文件文本会发送给你配置的模型服务。

隐私与控制

Persona 文件、设置、对话、记忆、日历和待办默认保存在设备本地，Provider 凭据使用 Android Keystore 支持的安全存储。

  • 独立保存 AI 与语音账号，由你明确选择当前连接。
  • 只启用你信任的工具与技能。
  • 仅在定位工具执行时请求当前位置。
  • 整个应用开源，可直接审查实现。

本地优先不等于完全离线：模型请求、可选云端语音和已启用的外部工具会将必要内容发送给对应服务。

设置 → 分享/导入支持勾选多个连接，导入时新增账号而非覆盖。持有完整分享链接的人可以使用其中的凭据并消耗额度，请只分享给可信的人。
