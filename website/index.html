Smart home · Mi Home

Control supported appliances and TVs, inspect device state, trigger scenes, and view the latest available camera event image in a foreground conversation.

“Turn off the living room TV.”
Get Mi Home extension ↓
Connect in three steps
  1. Install the extension from the same release/signing channel as Mochi.
  2. In Tools → Extensions → Mi Home, scan the login QR with another phone signed into Mi Home; select your devices.
  3. Return to Mochi and choose Enable tools and Skill when ready. Installation alone does not enable access.

Unofficial connector; capabilities vary by device. Event images are not live video. Control is foreground-only; acceptance is not proof of a physical result when a device cannot report its state.

Get Termux extension ↓ Install official Termux ↗
Connect in three steps
  1. Install Termux separately, plus the matching Mochi extension.
  2. Open Termux setup from Mochi Tools. Follow the external-command and Android permission guidance, then test the connection.
  3. Enable the Provider, Tools, and Skill you need. Manage submitted jobs in Tasks; disabling access blocks new calls, not existing jobs.

Full shell access under Termux permissions, not root or a sandbox. Enabled commands run without per-command confirmation. Output used by the Agent goes to your model provider.

A separate product, not a Mochi extension APK. Requires a running computer Bridge and a signed-in coding agent. Mochi access is explicitly granted and foreground-only; remote work can continue after Mochi closes.

Mi Home and Termux extensions have no separate launcher icon: open them from Mochi Tools. AgentLink has its own app. None is required for basic Mochi use; connect and enable only what you trust.

Privacy starts locally

Your companion.
Your provider. Your choices.

Persona files, settings, conversations, memory, calendar, and todos stay on the device by default. Provider credentials use Android Keystore-backed storage.

  • ✓ Save and explicitly switch independent AI and speech accounts
  • ✓ Enable only the Tools and Skills you trust
  • ✓ Location is requested only when a location Tool runs
  • ✓ Review the implementation—the entire app is open source

Local-first does not mean fully offline: model requests, optional cloud speech, and enabled external Tools send necessary content to their configured services. In Settings, Share/import lets you select multiple saved connections; importing adds accounts rather than overwriting them. Anyone holding the full share link can use its included credentials and consume quota. Share it only with people you trust.

Bring Mochi home

Three steps to a more useful phone.

No Mochi account or Mochi subscription. Bring your own AI service; provider usage and optional cloud speech may incur charges.

  1. 1
    Install or update

    Download v1.0.13. Choose arm64-v8a for most phones, armeabi-v7a for older ARM devices, or universal if unsure. Update through the same signing channel without uninstalling to preserve your data.

  2. 2
    Add a connection

    Open Settings → AI connections → Add AI connection. Choose a preset, then enter your model and API key. Later additions do not change your current connection; select Use to switch. Switching AI cancels running local Agent tasks.

  3. 3
    Talk your way

    Type or grant microphone permission to talk; enable “Hi Mochi” when ready. Android speech is built in. Optionally add a speech connection and select Use; switching speech stops the voice interaction and preview, not text or background work.
